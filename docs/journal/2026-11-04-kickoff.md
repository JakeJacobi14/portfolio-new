# 2026-11-04 — Kickoff

**Milestone:** concept

## What I set out to do
Start my own portfolio site: something creative and clearly mine, minimal, and free to host.

## What happened
- Hadn't had a strong idea until I saw a reel of the IgnitronDev studio site
  (ignitrondev.space), where swarms of little cursor "agents" appear to build the page
  live — drawing wireframes and guides before the content settles in.
  Frames: [`../inspiration/2026-11-04-ignitrondev-reel-frames.jpg`](../inspiration/2026-11-04-ignitrondev-reel-frames.jpg)
- Liked the idea of *watching the site get built*, but it's too cluttered for me. Direction:
  the same idea, much more restrained.
- Looked at Cindy Ly's portfolio (cindyly.design) as proof that an AI-built ("vibecoded") site
  can still feel personal. Takeaway: the AI writes the code, but the concept, rules and
  personal details have to come from me.
- Chose a free pipeline: Astro + GitHub + Vercel Hobby, built with Claude Code.
  See [ADR 0001](../decisions/0001-stack-and-hosting.md).
- Set up this documentation system because the portfolio will likely be a portfolio entry itself.
